# LLMO — 브랜드·엔티티 일관성

확인 기준일: 2026-08-27

"모델 자체의 지식에 브랜드를 심는다"는 표현은 지나치게 단정적일 수 있다.
이 레인의 실제 목표는 **웹 전반의 공개 정보에서 브랜드/조직/제품의 정체성과 핵심 사실을 일관되게 유지하고, AI 답변에서 그 정확성을 관찰하는 것**이다.

## 1. 엔티티 일관성

- [OFFICIAL] 구조화 데이터를 사용할 때 Organization/Product/ProfilePage 등 실제 엔티티와 일치하게 표현한다.
- [OBSERVED] 브랜드명, 공식 URL, 로고, 설명이 채널마다 제각각이면 사람과 시스템 모두 혼동하기 쉽다.
- [OBSERVED] `sameAs`는 실제 공식 프로필/식별 가능한 관련 페이지를 연결하는 용도로 사용한다.
- [EXPERIMENTAL] sameAs가 LLM 내부 기억을 직접 강화한다고 단정하지 않는다.

## 2. 공개 표면 관리

관리 대상 예:
- 공식 웹사이트
- GitHub
- 앱스토어
- 공식 소셜 계정
- 제품 문서
- 기술 블로그
- 신뢰할 수 있는 제3자 보도/리뷰

원칙:
- 사실 중심
- 동일한 핵심 설명
- 날짜가 바뀌는 정보는 갱신
- 억지로 위키/커뮤니티 문서를 만들거나 조작하지 않음

## 3. 하지 말 것

- 위키·커뮤니티에 이해관계 숨기고 홍보성 문서 작성
- 보도자료를 대량 복제하면 모델이 반드시 학습한다는 주장
- 허위 언론 노출·가짜 리뷰·가짜 전문가 프로필
- "몇 주 뒤 모델에 학습된다" 같은 기간 보장

## 4. 측정

분기 또는 큰 변경 후 다음 질문을 여러 모델/검색 모드에서 반복 기록한다.

- "[브랜드]가 뭐야?"
- "[브랜드]의 공식 사이트는?"
- "[브랜드]의 주요 기능은?"
- "[브랜드]와 [경쟁사] 차이는?"

기록:
- 정확/부분정확/오류/모름
- 출처 사용 여부
- 잘못된 사실
- 오래된 사실
- 이름 충돌 여부

브라우징을 끈 모델의 답변은 학습 데이터뿐 아니라 모델 버전·시스템 설정 등 많은 변수에 영향을 받는다.
따라서 **진단 신호**로만 사용하고 직접적인 최적화 효과로 해석하지 않는다.

## 5. 목표

"모델에게 브랜드를 심기"가 아니라:
1. 공개 웹의 사실을 일관되게 만들고
2. 신뢰 가능한 원출처를 제공하며
3. AI/검색에서 잘못된 설명이 줄어드는지 측정한다.
