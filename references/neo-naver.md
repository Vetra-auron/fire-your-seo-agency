# NEO — Naver 검색·AI 브리핑

확인 기준일: 2026-08-27

한국 대상 사이트에서는 Naver를 별도 레인으로 점검할 가치가 있다.
다만 **네이버 공식 검색 가이드와 AI 브리핑 인용에 대한 실측 가설을 분리**한다.

## 1. Naver Search Advisor 기반

[OFFICIAL]

- [ ] 사이트 소유 확인과 Search Advisor 등록
- [ ] robots.txt에서 Yeti 접근 정책 확인
- [ ] sitemap 제출/발견 가능 여부 확인
- [ ] 페이지 제목·설명·canonical 등 기본 검색 최적화 확인
- [ ] 모바일 환경에서 주요 콘텐츠와 링크가 정상 동작하는지 확인
- [ ] 웹마스터도구에서 제공되는 수집/색인/검색 지표를 관찰

출처: https://searchadvisor.naver.com/guide

## 2. AI 브리핑 관찰 항목

아래는 공식 랭킹 공식이 아니라 **[OBSERVED]/[EXPERIMENTAL]** 항목이다.

- [OBSERVED] 날짜·수치·출처가 분명한 구조화된 사실 페이지가 출처로 사용되는 사례가 있다.
- [OBSERVED] 최신 이슈/데이터에서는 신선도가 유리하게 보이는 사례가 있다.
- [OBSERVED] 모바일에서 핵심 내용을 빠르게 확인할 수 있는 구조는 사용자 경험에도 유리하다.
- [EXPERIMENTAL] 항목-값 표, 독립 문단, 1차 데이터가 AI 브리핑 인용률에 미치는 효과를 질문 세트로 측정한다.

"이 조건을 만족하면 AI 브리핑에 인용된다"라고 표현하지 않는다.

## 3. Naver 블로그와 외부 도메인

- [OBSERVED] Naver 내부 콘텐츠와 자체 도메인은 서로 다른 역할을 할 수 있다.
- [EXPERIMENTAL] 브랜드 블로그는 발견/설명 채널, 자체 도메인은 데이터/도구의 정본으로 운용하는 투트랙을 테스트할 수 있다.
- [OFFICIAL] 검색 노출을 조작하기 위한 스팸·자동화·링크 조작을 하지 않는다.

## 4. 하지 말 것

- 댓글/서로이웃/반복 문구 자동화
- 동일 콘텐츠 대량 복제
- 허위 리뷰/체험
- 검색 순위 보장
- "발행 후 수정하면 문서 신뢰 점수가 깎인다"처럼 공식 근거 없는 규칙을 절대 규칙으로 사용

## 5. 측정

주간:
- Search Advisor에서 확인 가능한 검색/수집 지표
- 주요 URL 색인/노출 상태
- 대표 검색어 변화

AI 브리핑:
- 고정 질문 5~10개
- 인용 출처 URL
- 우리 도메인 포함 여부
- 답변 정확성
- 측정일

계절성·요일효과는 업종별로 다르므로 "주말 하락 = 실수요 증거"로 일반화하지 않는다.
